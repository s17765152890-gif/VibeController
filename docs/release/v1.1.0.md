# VibeController v1.1.0

DualSense 体验与 Codex 状态灯更新。<br>
DualSense experience and Codex status-light update.

## 主要更新 / Highlights

- 优化 PS5 DualSense 摇杆的连续采样与光标移动，降低蓝牙模式下的卡顿。<br>
  Improved continuous DualSense stick sampling and pointer movement, especially over Bluetooth.
- 设置页新增 Windows 默认录音端点与 DualSense 麦克风可用性检测；检测只读取设备名称，不录音。<br>
  Added read-only detection for the Windows default recording endpoint and DualSense microphone availability.
- 新增 DualSense 灯条输出，支持 USB 与蓝牙 HID 报告及蓝牙 CRC。<br>
  Added DualSense lightbar output for USB and Bluetooth HID reports, including Bluetooth CRC generation.
- 可选的 Codex 状态桥接：蓝色呼吸表示工作中，琥珀色表示等待操作，绿色表示本轮完成。<br>
  Added an optional Codex status bridge: breathing blue for working, amber for attention, and green for completion.
- 修复 Windows PowerShell 无法执行带空格路径的 Hook 命令；Hook JSON 现在会显式转发给 VibeController。<br>
  Fixed PowerShell execution of Hook commands whose application path contains spaces, with explicit JSON forwarding.
- 当 Codex Desktop 漏发 `Stop` Hook 时，15 秒无新活动后自动显示完成状态，避免灯条永久停留在工作中。<br>
  Added a 15-second inactivity fallback when Codex Desktop omits the `Stop` Hook, preventing a permanently working light.
- 设置页补充状态灯开关、麦克风状态和集成错误反馈，并完善对应自动化测试与硬件验收说明。<br>
  Expanded Settings with lightbar controls, microphone status, integration errors, automated coverage, and hardware QA guidance.

## 安装与升级 / Install and upgrade

1. 下载 `VibeController-v1.1.0-win-x64.zip` 和同名 `.sha256` 文件。<br>
   Download `VibeController-v1.1.0-win-x64.zip` and its matching `.sha256` file.
2. 完整解压到一个新目录，不要覆盖正在运行的旧版本。<br>
   Extract the full archive into a new directory instead of overwriting a running copy.
3. 退出旧版 VibeController，再运行新版 `VibeController.App.exe`。现有设置会继续从 `%LOCALAPPDATA%\VibeController\settings.json` 读取。<br>
   Exit the old app and launch the new `VibeController.App.exe`. Existing settings remain in `%LOCALAPPDATA%\VibeController\settings.json`.
4. 如果启用了 Codex 状态灯，请在 Codex 提示时重新审核并信任更新后的 Hook。<br>
   If the Codex status light is enabled, review and trust the updated Hook when Codex prompts you.

## 已知限制 / Known limitations

- Windows x64 only; binaries are unsigned and may trigger SmartScreen.
- Standard DualSense Bluetooth pairing usually does not expose the controller microphone to Windows.
- Codex Desktop may omit the `Stop` lifecycle Hook in some sessions; VibeController uses the inactivity fallback described above.
- The completion fallback is an approximation: unusually long periods without lifecycle activity can be interpreted as completion.
