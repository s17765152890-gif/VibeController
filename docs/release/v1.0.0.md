# VibeController v1.0.0

首个公开版本：用 Xbox Series X|S 或 PS5 DualSense 手柄控制 Windows 版 Codex。<br>
First public release: control Codex for Windows with an Xbox Series X|S or PS5 DualSense controller.

## 主要功能 / Highlights

- Xbox XInput 与 PS5 DualSense USB/蓝牙 HID 支持。<br>
  Xbox XInput and PS5 DualSense USB/Bluetooth HID support.
- 可视化设备切换、实时输入反馈与按键映射编辑。<br>
  Visual device switching, live input feedback, and mapping editor.
- DualSense 触控板移动鼠标，按下执行左键单击。<br>
  DualSense touchpad mouse movement and press-to-click.
- 自动读取并热刷新用户自己的 Codex 快捷键配置。<br>
  Lazy resolution and hot refresh of each user's Codex shortcut configuration.
- Codex 前台保护、暂停映射、无注入测试模式、本地设置和系统托盘。<br>
  Codex foreground guard, mapping pause, non-injecting test mode, local settings, and system tray.

## 安装 / Install

下载 `VibeController-v1.0.0-win-x64.zip`，完整解压后运行 `VibeController.App.exe`。该包自带 .NET 运行时；仍需要 Microsoft Edge WebView2 Runtime。

Download `VibeController-v1.0.0-win-x64.zip`, extract it completely, and run `VibeController.App.exe`. The .NET runtime is included; Microsoft Edge WebView2 Runtime is still required.

二进制尚未签名，SmartScreen 可能警告。请同时下载 `.sha256` 并核对哈希。<br>
The binary is currently unsigned and may trigger SmartScreen. Download the `.sha256` asset and verify the hash.

## 首次使用注意 / First-run note

Codex 通常没有给“切换听写”和“提高/降低推理强度”分配默认快捷键。请先在 Codex 设置中绑定；VibeController 会读取每位用户实际设置的按键，不要求统一组合键。

Codex commonly has no default shortcuts for Toggle Dictation or Increase/Decrease Reasoning Effort. Bind them in Codex Settings first; VibeController reads each user's actual combinations.

更多说明见压缩包内的 `README.md` 或项目主页。<br>
See the bundled `README.md` or the repository homepage for the complete guide.

## 已知限制 / Known limitations

- Windows x64 only; no installer, auto-update, or code signing yet.
- Xbox Guide and other OS-reserved inputs are not core mappings.
- DualSense support has automated coverage; additional real-hardware firmware/adapter reports are welcome.
