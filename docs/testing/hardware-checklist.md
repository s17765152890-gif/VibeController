# Xbox Series X|S / PS5 DualSense 手柄验收清单

测试日期：____　Windows 版本：____　设备：Xbox / PS5 DualSense　连接方式：蓝牙 / USB / Wireless Adapter

## 连接与可视化

- [ ] 启动前已在 Windows 中连接手柄，应用在 2 秒内显示“已连接”
- [ ] A/B/X/Y、方向键、LB/RB、LT/RT、Menu/View、L3/R3 按下与释放均实时显示
- [ ] 两个摇杆的方向和幅度正确，中心位置不漂移
- [ ] 切换控制器 1–4 后只读取选中的设备
- [ ] 测试模式下所有输入有视觉反馈，但不产生键盘或鼠标输出
- [ ] 在设置中切换 Xbox / PS5 后，旧设备停止输入，新设备无需重启应用即可连接

## PS5 DualSense 专项

- [ ] □/×/○/△、方向键、L1/R1、L2/R2、Options/Create、L3/R3 均实时显示
- [ ] USB 连接和蓝牙连接都能持续读取输入，断开后在 2 秒内显示未连接
- [ ] 触控板第一次接触不会令鼠标跳变，随后滑动方向与鼠标方向一致
- [ ] 触控板抬起再接触不会沿用上一次坐标；按下只产生一次鼠标左键单击
- [ ] 左摇杆向任一方向保持 10 秒，鼠标连续、匀速移动，不出现只在轻微抖动时才移动的卡顿
- [ ] 分别通过 USB 与蓝牙重复上一项；触控板与左摇杆的移动流畅度处于同一可用水平
- [ ] □/×/○/△ 分别与 Xbox 的 X/A/B/Y 执行相同默认操作
- [ ] L1/R1/L2/R2 分别与 Xbox 的 LB/RB/LT/RT 执行相同默认操作

## 听写麦克风检测

- [ ] 设置页显示的“Windows 默认听写麦克风”与 Windows 声音设置中的默认输入一致
- [ ] 点击“刷新检测”后，插拔 USB 麦克风或切换默认输入能更新名称，无需重启应用
- [ ] 仅用普通蓝牙连接 DualSense 时，若 Windows 没有相应录音端点，界面明确显示“当前不可用”并继续使用系统默认输入
- [ ] USB 连接且 Windows 实际出现 Wireless Controller / DualSense 录音端点时，界面显示“已发现录音端点”
- [ ] 检测过程不会点亮 Windows 麦克风正在使用指示，也不会生成录音文件

## DualSense 灯条与 Codex Hook

- [ ] 开关初始为关闭；未开启时不会创建或修改 `$CODEX_HOME\hooks.json`（未设置时为 `%USERPROFILE%\.codex\hooks.json`）
- [ ] 开启并保存后，已有 Hook 配置仍完整保留，并生成一次 `hooks.json.vibecontroller.bak`
- [ ] Codex 首次提示信任非托管 Hook 时，确认后后续事件可以运行
- [ ] 提交任务后灯条变蓝；任务处理期间保持蓝色
- [ ] Codex 等待权限时灯条变琥珀色，允许并继续执行后恢复蓝色
- [ ] 本轮完成后灯条变绿色，约 8 秒后回到暗蓝空闲色
- [ ] 同时运行两个 Codex 任务时，等待权限优先于工作中，工作中优先于已完成
- [ ] 分别在 USB 与蓝牙连接下执行以上颜色测试；输入读取与触控板不受灯条写入影响
- [ ] 关闭开关后只移除含 `--vibecontroller-codex-hook` 的处理器，其他用户 Hook 保持不变，灯条关闭

## Codex 默认映射

- [ ] Menu 将已运行的 Codex 带到前台
- [ ] 先在 Codex 中为“切换听写”绑定一个普通组合键；X 连续触发 10 次，Codex 每次均响应
- [ ] A 使用 Codex 当前的“发送消息”绑定，B 发送 `Backspace`，Y 使用当前“打开命令菜单”绑定
- [ ] LB/RB 分别触发“上一个任务”与“下一项任务”，不会误切换标签页
- [ ] 十字键左右逐级调整推理强度，按住不会连续跳过多个档位
- [ ] 右摇杆四方向映射为键盘方向键，按住可持续移动光标，回中立即停止
- [ ] 左摇杆移动鼠标，RT 左键单击，LT 右键单击
- [ ] 普通按钮长按不会重复触发；方向键在延迟后按配置连发

## 安全与恢复

- [ ] “仅在 Codex 前台时执行”开启时，记事本和浏览器不会收到输入
- [ ] 暂停映射后不产生任何键鼠输出，恢复后正常
- [ ] Codex 未运行或权限更高时显示拦截/失败信息，不向其他窗口补发
- [ ] 手柄休眠并唤醒 20 次，每次都无需重启应用自动恢复
- [ ] 重启应用后映射、控制器编号、死区、速度和听写快捷键保持不变
- [ ] 关闭窗口进入托盘；托盘的打开、暂停/启用和退出都正常
